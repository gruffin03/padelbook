Application web single-file (HTML/CSS/JS vanilla) hébergée sur Netlify.
3 types d'utilisateurs : Joueur (gratuit), Coach (abonnement), Admin.

**Why:** Plateforme de réservation de cours de padel avec coaches. Pas de paiement en ligne ni réservation de terrain — cours uniquement, paiement sur place.

**How to apply:** Toujours travailler dans `C:\Users\gruff\OneDrive\Bureau\PADELBOOK\padelbook\` (pas dans padel-tools-app qui est une autre app).

Fichier principal : `index.html` (renommé depuis padelbook.html)
Stack : Supabase (DB + Auth), Netlify (hébergement + Functions), Resend (emails), Google Calendar API, Stripe dans 3 mois.
